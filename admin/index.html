Publication editor

Edit your publication

Open Pages CMS and sign in with the GitHub account that owns this website. Select EHAARV01 / college-basketball and the main branch.

  • Homepage: change headings, introductions, previews, and the About section.
  • Publication settings: edit the publication name, byline, season, and navigation labels.
  • Articles: write and format stories, add images, and control whether an article appears on the website.

Save changes in the editor. GitHub then rebuilds the website; allow the deployment to finish before refreshing.
